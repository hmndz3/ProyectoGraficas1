# Música del juego

| Archivo | Nivel |
|---|---|
| `music1.ogg` (o `.wav`) | I. The Fool |
| `music2.ogg` (o `.wav`) | II. The Hanged Man |
| `music3.ogg` (o `.wav`) | III. The Hermit |

Formatos soportados: OGG y WAV. Si un archivo falta, ese nivel usa la
pista sintetizada de respaldo. El juego se ejecuta desde la raíz del
proyecto (`cargo run --release`) para que encuentre esta carpeta.
